# План: кооперативная игра по локальной сети

## Решения для MVP
- До 4 игроков всего; хост запускает локальный лаунчер одним действием. Лаунчер поднимает сервер и показывает LAN-адрес/порт, остальные открывают его в браузере.
- Кооперативный забег: отдельный герой и инвентарь у каждого, общее подземелье.
- Каждое принятое действие любого игрока продвигает общий ход; после него действуют враги.
- При разрыве соединения забег продолжается, герой остаётся в мире; игрок может вернуться по коду комнаты.
- Обычный браузер не может сам принимать входящие WebSocket-подключения, поэтому HTML-файл не будет самостоятельным хостом.
- Выбран локальный лаунчер с WebSocket-сервером вместо WebRTC: это даёт прямое подключение по адресу/порту без отдельного обмена сигналами между браузерами.

## Этапы
1. **Лаунчер, сервер и комнаты:** добавить запуск сервера одним действием, раздачу игры и WebSocket на одном порту; показывать LAN-адрес хоста, поддержать создание комнаты, лимит игроков, роли и переподключение по временному токену. По возможности упаковать Node.js, чтобы не требовать его отдельной установки.
2. **Общее состояние:** сохранить текущую браузерную симуляцию на стороне хоста как авторитетную; Node.js-сервер маршрутизирует разрешённые действия, держит последний снимок комнаты в памяти и рассылает его. Игровой API поддерживает нескольких героев, общие карту/врагов/предметы и отдельные характеристики игроков.
3. **Игровой интерфейс:** добавить создание/вход в комнату, лобби и список игроков; отправлять все игровые действия через сеть, показывать других героев и статусы соединения. Сохранить одиночный режим.
4. **Надёжность и инструкции:** обработать неверные команды, отключения, повторное подключение и завершение комнаты; описать запуск и подключение в README.

## Проверка готовности
- Тесты симуляции и сетевого протокола: авторизация игрока, лимит 4, валидация ходов, общий ход, отдельные герои, отключение/возврат.
- Ручная проверка в двух браузерах/устройствах в одной LAN: создание комнаты, совместная игра, отображение действий и переподключение.
- Регрессия одиночного режима: `node --test`; проверка запуска лаунчера и доступа к игре через LAN-адрес хоста.

> Переподключение хоста возможно, пока запущен Node.js-сервер; перезапуск сервера удаляет комнаты и снимки.
