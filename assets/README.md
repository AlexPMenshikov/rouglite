# Графические ресурсы

Игра поддерживает внешние PNG-тайлсеты 16×16, например `assets/tiny-dungeon.png` или `assets/spritesheet.png`. Порядок тайлов задаётся в `KENNEY_MAP` в `js/assets.js`; если файла или конкретного тайла нет, используется встроенный набор.

Для кастомного оформления полов и стен используйте изображения не менее 16×16:
- `floor-dark.png` / `wall-dark.png` для этажей 4–6;
- `floor-deep.png` / `wall-deep.png` для этажей 7–10.

Если этих файлов нет, система подставляет затемнённые встроенные текстуры.

Перед использованием внешних ресурсов проверьте лицензию: CC0, CC-BY, CC-BY-SA и NC имеют разные ограничения. Пример: Kenney Tiny Dungeon распространяется по CC0.
