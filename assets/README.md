# Графические ресурсы

Игра включает встроенные пиксельные спрайты 16×16 для персонажей, врагов,
боссов и предметов. Внешний тайлсет можно добавить как
`assets/tiny-dungeon.png` или `assets/spritesheet.png`: сетка 16×16, порядок
тайлов описан в `KENNEY_MAP` в `js/assets.js` (первые 17 позиций совместимы
с базовым набором, дополнительные asset-имена включают ключи, экипировку и
боссов). PNG-тайлсет включается и отключается в меню; настройка хранится
в браузере. Если файла или тайла нет, используются встроенные спрайты.

Для вариантов пола и стен используйте PNG не меньше 16×16:
`floor-dark.png` / `wall-dark.png` для этажей 4–6 и
`floor-deep.png` / `wall-deep.png` для этажей 7–10. Отсутствующие тайлы
заменяются затемнёнными встроенными.

Перед добавлением внешних ресурсов проверьте лицензию: CC0 свободна, CC-BY
требует указать автора, CC-BY-SA распространяет условия на производные,
NC запрещает коммерческое использование. Например, [Kenney Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon)
распространяется по CC0.
