# Тесты

Требуется Node.js 18 или новее. Запуск из корня проекта:

```powershell
node --test
```

`game-loop.test.js` загружает игровые скрипты и проверяет публичный API: запуск
этажа, ходьбу и подбор предмета, атаку и учет добычи, а также иконки итогового
экрана. Новые проверки добавляйте в `tests/`, вызывая те же методы `RK.Combat`,
которые использует игра; общие браузерные заглушки находятся в файле тестов.

Проверки классов автоматически обходят `RK.Classes.CLASS_DEFS`: при добавлении
класса базовые тесты проверят запуск забега и активацию его навыка. Для новой
уникальной пассивной способности или эффекта навыка добавьте отдельный тест,
который проверяет результат через игровой API; не фиксируйте список классов в
общем тесте.

Все тесты обходятся без браузера.

`lan-server.test.js` проверяет создание комнаты, подключение и возврат игрока по
токену, маршрутизацию игровых команд, лимит игроков и раздачу игры по HTTP.
Тестам LAN-сервера требуется установленная зависимость `ws` из корневого
`package.json`.
