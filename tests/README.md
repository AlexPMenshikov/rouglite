# Тесты

Требуется Node.js 18+. Запуск из корня проекта:

```powershell
node --test
```

Что покрывают проверки:

- `game-loop.test.js`: публичный API игры, запуск этажа, движение, подбор предметов, бой, награды и иконки финального экрана;
- `lan-server.test.js`: комнаты, подключение игроков, повторное подключение по токену, маршрутизация игровых команд, лимит игроков и раздача игры по HTTP.
- `network-focus.test.js`: проверка рендера для игры по сети.

Тесты работают без браузера. Для сетевых проверок нужен пакет `ws` из корневого `package.json`.
