# План: Мир с локациями (Location-based World)

## Видение
**Локации с переходами** — города, дикая природа, данжи как отдельные сцены с загрузкой.
Приоритет: **исследование**. Масштаб: **эволюция текущего кода**.

---

## Прогресс реализации (текущая сессия)

- [x] Граф мира: три локации `city_start`, `wilderness_forest`, `dungeon_crypt` связаны выходами.
- [x] Переходы между локациями работают в обе стороны; состояние каждой локации сохраняется при уходе и восстанавливается при возврате.
- [x] Введены типы локаций (`city`, `wilderness`, `crypt`) с профилями генерации `spawnRate`.
- [x] Город не спавнит врагов; торговец и кузнец появляются только в городе.
- [x] Дикая природа генерирует 3 POI (поляна, роща, руины) и дороги от спавна к ним.
- [x] Данж (склеп) использует текущий алгоритм генерации как локацию графа, босс только в данжах.
- [x] Состояние мира включено в сетевые снимки (`createSnapshot`/`applySnapshot`).
- [x] Отрисовка выходов и POI на карте (графика + ASCII).
- [x] HUD показывает название текущей локации.
- [x] Вход в локацию грузит сцену целиком: спавн врагов, предметы, торговец и кузнец в городе, восстановление состояния при возврате (`World` → `Combat.startFloor`).
- [x] Тестирование: `tests/world.test.js` — переходы, сохранение состояния, сетевые снимки, генерация wilderness.
- [x] Сетевой забег идёт по миру локаций: `world.js` добавлен в `ENGINE_SCRIPTS`, переходы считает сервер, состояние локаций едет в снимке.
- [x] Партия встаёт на переходе не в одну клетку: сосед больше не занимает клетку выхода и не блокирует обратный переход.
- [x] Карта текущей локации не дублируется в снимке (едет полем `map`), что уменьшило сообщение примерно вдвое.
- [x] Сжатие снимка: матрицы карты едут парами в `map.matrices`, `map.vis` убран — 42 KB → 18 KB на локацию.
- [x] Сохранение одиночного забега в `localStorage` и кнопка «Продолжить забег» в меню; битое сохранение даёт новый забег.
- [x] Сохранение сетевого забега на диске сервера (`data/runs/`): переживает перезапуск, герои возвращаются по токену.
- [x] Комната без игроков удаляется через 20 минут, забег перед этим ложится на диск.
- [x] Лимит действий поднят выше темпа ходьбы: игрок, держащий клавишу, больше не получает «Слишком много действий».
- [x] Генерация города: крепостная стена, кольцевая дорога, сетка улиц, площадь и дома-кварталы с открытыми дверями; проспект от ворот до площади.

## Стратегия интеграции

1. Ветка `feature/world` — весь новый код.
2. Шим `MapGen.generateLocation(type, ...)` — делегирует к старому `generate()` для подземелий, к `generateCity()` для города и к `placeWilderness()` для леса.
3. Флаг `ENABLE_WORLD = true` в конфиге — мир включён; `false` возвращает legacy-режим этажей.
