# План: Мир с локациями (Location-based World)

## Видение
**Локации с переходами** — города, дикая природа, данжи как отдельные сцены с загрузкой.
Приоритет: **исследование**. Масштаб: **эволюция текущего кода**.

---

## Прогресс реализации (текущая сессия)

### Выполнено

- [x] Граф мира: три локации `city_start`, `wilderness_forest`, `dungeon_crypt` связаны выходами.
- [x] Переходы между локациями работают в обе стороны; состояние каждой локации сохраняется при уходе и восстанавливается при возврате.

## Стратегия интеграции

1. Ветка `feature/world` — весь новый код.
2. Шим `MapGen.generateLocation(type, ...)` — делегирует к старому `generate()` для `type='dungeon'`.
3. Флаг `ENABLE_WORLD = false` в конфиге — старый флоу по умолчанию.
4. `Meta.migrateToWorld()` при первом запуске с флагом.
