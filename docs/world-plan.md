# План: Мир с локациями (Location-based World)

## Видение
**Локации с переходами** — города, дикая природа, данжи как отдельные сцены с загрузкой.
Приоритет: **исследование**. Масштаб: **эволюция текущего кода**.

---

## Архитектура
> **Локация = сцена с профилем MapGen + системами (NPC, квесты, спавн, правила перехода).**
> Мир = граф локаций. Игрок перемещается по рёбрам (пути, порталы, двери).

### Детали задачи 4.0 «Раскрашиваем локации»

Цель: каждая локация видна по цвету, свету и планировке залов, а не по номеру этажа.

Осталось:

- **4.0.3.** ✅ `bakeFloorLayer` откатывает неизвестный стиль зала к `mm.style`, а индекс палитры вне `colors`/`wallColors` — к нулевому цвету. Регресс-тест в `tests/render-mode.test.js`.
- **4.0.4.** ✅ Селект оформления знает все 8 стилей из `MAP_STYLES`.

Ограничения: без `Math.random` — карту считают и клиент, и сервер. Старты залов берёт `seededRandom` по seed карты, а не `RK.RNG`: иначе при том же seed сдвинулись бы позиции врагов, предметов и сундуков. Снимок не растёт: `regions` уже в кодеках, `regionStyles` — короткий массив строк. Строки интерфейса и доков — по-русски.
