# План: производительность, долгоживущие комнаты, очистка

Дата: 2026-10-27.

## Узкие места

Основная нагрузка — серверный цикл хода:

`applyAction` → `run.snapshot()` → `World.saveCurrentState()` + `World.getNetworkState()` →
`changedSinceBroadcast` + `broadcast`.

На каждом шаге создаются глубокие клоны карты/мира и делается `JSON.stringify` для
сравнения частей снимка.

## Этап A — быстрый выигрыш [выполнено]

1. Кэшировать `RK.World.getNetworkState()`, инвалидировать только при смене локации или входящем
   состоянии.
2. Убрать deep clone из `saveCurrentState()` в `RK.Combat.createSnapshot()` и `finishTurn`; оставить
   вызовы при переходах, `init` и `applySnapshot`.
3. В `RoomManager.publish` сравнивать `map`/`world` по лёгкому ключу, а не через `JSON.stringify`.
4. Кэшировать `vm.Script` для `ENGINE_SCRIPTS`, чтобы не компилировать заново на каждую комнату.
