# Улучшения интерфейса и игрового поля

## 1. Журнал на экране настроек
- Журнал боя убран с игрового экрана и лежит снизу экрана настроек во всю ширину.
- `js/ui-settings.js`: `logCollapsed` default `false`; сохранять состояние в `localStorage`.
- Игровое поле больше не делит место с журналом.

## 6. Уровень и задание на главном экране
- Убрать `stat-level` и `stat-quest` из HUD.
- Показать уровень в окне персонажа / `stats-panel`.
- Журнал остаётся источником квестов; отдельный пункт «Задание» убрать.

## 7. Максимальное игровое поле, база 1920×1080
- `AGENTS.md`: базовый отсчёт 1920×1080.
- CSS: игровое поле занимает максимальное свободное место, фиксированные ограничения не мешают.
- Render: viewport/COLS/ROWS и canvas пересчитываются по доступной области, включая смену состояния журнала.

## Дополнительно зафиксировано в харнессе
- Основная цель — PC (клавиатура/мышь); планшеты и телефоны отложены.
- Поле использует максимум свободного места, базовый отсчёт 1920×1080.

## 8. Панель способностей в HUD
- В HUD отдельный ряд `#hud-skills`: три кнопки способностей класса.
- Кнопка показывает имя навыка, его клавишу (1/2/3) и состояние:
  «Готов», «Перезарядка: N хд.» с полосой отката, «Откроется на N ур.» для закрытых навыков,
  «Выберите цель» для подготовленного заклинания мага.
- Клик по кнопке применяет навык: в сети уходит `activateClassSkill` с id навыка,
  откаты приезжают в снимке вместе с остальным состоянием.
- Кнопка «Навык (Q)» и строка «Навык» в панели «Персонаж» убраны: панель их заменила.
- Источник отката один — `player.skillCooldowns[id]`; зеркало `classSkillCooldown` удалено.
- Описания навыков остались на экране «Навыки».
