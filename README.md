# Рогалик

Браузерный roguelite с процедурными этажами, боем, лутом и кооперативом по локальной сети. Открывайте `rougelite.html` в современном браузере и проходите подземелье до 10-го этажа.

## Что есть сейчас

- процедурная генерация этажей, враги и боссы;
- классы, уровни, инвентарь, экипировка, магазин и постоянные улучшения;
- одиночный режим и совместный забег до 4 игроков по LAN;
- сохранение прогресса и комнаты между перезапусками сервера/браузера в рамках активной сессии.

## Управление

- движение: WASD / стрелки / мышь;
- взаимодействие: `E`;
- вскрытие замка: `L`;
- разбить/выбить: `F`;
- зелье: `R`;
- навык класса: `Q`;
- fullscreen: `F11`.

## Запуск

1. Одиночная игра: открыть `rougelite.html`.
2. LAN-кооператив: установить Node.js 18+, запустить `start.bat` на хосте. Сервер поднимется автоматически и покажет LAN-адрес и порт. Остальные игроки подключаются по этому адресу, вводят код комнаты и имя.
3. Хост создаёт комнату и начинает забег. Игровая симуляция выполняется в браузере хоста, а Node.js-сервер хранит состояние комнаты и маршрутизирует действия.

## Статус проекта

Готово:
- процедурные карты, бой, инвентарь, улучшения, кооператив по LAN, одиночный режим, тесты.

В работе:
- балансировка и расширение API-тестов.

Планы:
- ловушки в сундуках, поведение врагов у дверей, новые окружения и препятствия.

Тесты запускаются так: `node --test`.
