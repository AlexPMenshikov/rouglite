# Рогалик

Браузерный roguelite с процедурными этажами, боем, лутом и кооперативом по LAN. Открыть `rougelite.html` в браузере.

## Особенности

- процедурная генерация этажей (камень/пещера/склеп), враги, боссы, классы, уровни
- **классы**: танк (защита и отражение урона), берсерк (ярость и лечение от урона), лучник (стрельба на расстоянии видимости, чутьё на ловушки)
- инвентарь с сортировкой по ценности/редкости/типу и фильтрами, экипировка, постоянные улучшения, банк золота
- **таверна** — безопасная комната с торговцем и кузнецом (враги могут заходить)
- **кузнец** — улучшение надетой экипировки до 5 уровней (+15% базовых статов/уровень)
- **торговец** — задания (убить демонов / найти предметы) за золото
- **озерца и ручьи** в больших комнатах (декор, не блокируют проход)
- **ловушки** в комнатах (штыри, иглы, пламя — взвод, отмычка, срабатывание); лучник видит их за 2 клетки, обезвреживает чаще и может переставить свою
- одиночный режим и LAN-кооператив до 4 игроков (состояние на хосте)
- сохранение прогресса и комнаты между перезапусками
- ASCII / пиксельная графика (переключение кнопкой «Вид»), F11 — фуллскрин

## Классы

| Класс | Оружие | Особенности |
|---|---|---|
| Танк | меч, топор | защита и здоровье, «Щитовой ответ» |
| Берсерк | меч, топор | атака и лечение от урона, «Безумие» |
| Лучник | лук, арбалет | выстрел кликом мыши на расстоянии видимости, чутьё на ловушки, «Прицельный выстрел» |

## Управление

| Действие | Клавиши |
|---|---|
| Движение | WASD / стрелки / мышь / нумпад |
| Выстрел (лучник) | клик мышью по врагу в пределах видимости |
| Взаимодействие (двери, сундуки, NPC) | `E` |
| Вскрыть замок / обезвредить ловушку | `L` |
| Выбить / сломать | `F` |
| Зелье лечения | `R` |
| Навык класса | `Q` |
| Пропустить ход | `5` / `.` |
| Выход из комнаты отладки | `Esc` |

## Запуск

1. **Одиночная игра**: задать имя героя → открыть `rougelite.html`
2. **LAN-кооператив**: Node.js 18+ → `start.bat` / `start.sh` на хосте → остальные открывают адрес из консоли, вводят код комнаты и имя
3. **Тесты**: `node --test` (нужен `ws` из `package.json`)

## Ресурсы

Внешние PNG-тайлсеты 16×16 (например `assets/tiny-dungeon.png`). Порядок тайлов — `KENNEY_MAP` в `js/assets.js`. Кастомные полы/стены: `floor-dark.png`, `wall-dark.png` (этажи 4–6), `floor-deep.png`, `wall-deep.png` (этажи 7–10). Проверяйте лицензии (CC0, CC-BY и др.).
