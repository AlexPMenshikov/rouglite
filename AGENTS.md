# AGENTS.md

Браузерный roguelite: одиночная игра в браузере, LAN-кооператив с авторитетным сервером.
Комментарии, строки интерфейса, документация и сообщения коммитов — на русском.
Сборки нет: ни бандлера, ни ES-модулей, ни TypeScript.

## Документы

Перед планированием и перед проверкой готовой реализации читай:

- `docs/architecture.md` — карта файлов, состояние забега, потоки, инварианты и рецепты расширения;
- `docs/lan-protocol.md` — сообщения, снимок, сжатие, безопасность и порядок добавления действия.

Если правка меняет архитектуру, состояние, поток хода или протокол — дополни нужный документ в том же коммите. Один факт живёт в одном месте: подробности — в `docs/`, здесь только правила работы. Имена файлов сверяй со `scripts/script-list.js`, а не со старыми текстами.

## Команды

- `npm install` — единственная зависимость `ws`; Node >= 18.
- `npm start` — LAN-сервер на `0.0.0.0`, порт из `PORT` или автоматически; на Windows открывает вкладку.
- `npm test` — `lint` → `test:unit` → `test:integration`, порядок важен.
- `npm run lint` — `scripts/check-syntax.js`: разбирает скрипты из HTML (сверяя порядок с `BROWSER_SCRIPTS`) и все `server/*.js`, `scripts/*.js`.
- Один тест: `node --test tests/<feature>.test.js`.
- Категория теста выводится из имени файла (`scripts/run-tests.js`); новый файл списков не требует.
- CI: Node 20 и 22, `npm ci` + `npm test`.

## Режим игры

Старт в городе, дальше — переходы по графу локаций. На каждой локации есть подземелье до 4 ярусов с боссами, врагами и предметами из материнской локации. Забег кончается только смертью героя или выходом в главное меню.

## Платформа и эксплуатация

- Цель — PC (клавиатура и мышь); мобильные устройства и планшеты отложены.
- Игровое поле занимает максимум экрана; базовый отсчёт 1920×1080.
- Docker: процесс идёт не от root, `PORT` (3000 в `docker-compose.yml`), `RUNS_DIR=/app/data/runs` на именованном томе; healthcheck делает GET на `/`.

## Разработка

- Новые ассеты: генерация в `scripts/generate-tileset.js`, затем обновить `assets/README.md`.
- Тесты изолированные и детерминированные: seed задаётся явно или счётчиком. Харнес — `tests/helpers/sandbox.js`, свой DOM-стаб не писать.
- Список клавиш живёт в игровой справке; не дублируй его в README. Справка собирает классы из `CLASS_DEFS`, а лимит комнаты — из `CONFIG.MAX_PLAYERS`; README обязан называть классы и вместимость в виде «до N игроков», это сверяет `tests/docs-facts.test.js`.
- Старые сейвы можно ломать с разрешения пользователя: при несовместимом формате поднимай `SAVE_VERSION`, старый файл должен молча уйти.
- Ключ мета-прогресса в `localStorage` — намеренно с опечаткой: `rogalite_meta_v1` (`CONFIG.META_KEY`). Не переименовывать: тесты и сейвы зависят.
- Прежде чем решать, что что-то сломано, проверь `git log` и `git status`. Состояние планов — в `docs/world-plan.md` и `docs/tech-debt-plan.md`.
- История: ветки `agents/*` вливаются в `main`; сообщения коммитов на русском.
